# Dependency patches

Document every pnpm dependency patch in `PATCHES.md`. Each entry must include:

- The package and version.
- A link to the patch file.
- The reason for the patch.
- The errors or behavior it fixes.
- When the patch can be removed.

Update or remove the matching `PATCHES.md` entry when a patch changes or is
removed.
